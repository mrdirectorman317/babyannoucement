# Baby announcement page (archived)

The original single-page baby announcement site (countdown, glow, voting board) that
used to live at the root of this repository. It is kept here, unchanged, so nothing is lost.

- The original, live version is still on the `main` branch (`/index.html`).
- If GitHub Pages serves `main`, the public page keeps working until `main` is changed.
- To restore it, copy `index.html` back to the repo root.
